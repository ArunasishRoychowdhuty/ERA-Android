# ERA Android Assistant

Repository containing the development versions and source code for the ERA Native Android Assistant project.

## Directory Structure

- **`ERA-Android-v0.8.0-dev/`**: Latest development version (v0.8.0-dev) including compact accessibility JSON, visual fallback policy, unit tests, and GitHub Actions CI workflow.
- **`ERA-Android-v0.7.2/`**: Hardened test pipeline with smoke suite and automated checks.
- **`ERA-Android-v0.7.1/`**: Permission center foundation and core architecture.
- **`ERA-Android-v0.7.2-pre-v0.8-backup.tar.gz`**: Pre-v0.8 milestone backup archive.
